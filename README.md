🃏 TCB – Trabalho de Conclusão do Bimestre 

📌 Sobre o Projeto

Este repositório contém um projeto de desenvolvimento prático focado na recriação das mecânicas principais do jogo Balatro. O objetivo principal é consolidar conhecimentos em desenvolvimento Full-Stack, exercitando tanto a lógica do Back-End quanto a interatividade do Front-End e a comunicação entre ambos.

🎯 Objetivos de Aprendizado

Desenvolvimento Back-End: Praticar a linguagem Java na construção das regras de negócio, manipulação de baralhos, validação de jogadas e sistema de pontuação além da conexão com banco de dados do MySQL.

Desenvolvimento Front-End: Criar uma interface visual responsiva utilizando HTML5, CSS3 e JavaScript puro (Vanilla JS).

Integração Full-Stack: Implementar a comunicação e o fluxo de dados entre a aplicação em Java (Back-End) e a interface web (Front-End).

🛠️ Tecnologias Utilizadas

Back-End

Java: Lógica do jogo, gerenciamento de estados e processamento de regras.
MySQL: Salvamento do estado do jogo e ranking do jogador
Front-End

HTML5: Estruturação dos elementos da interface.

CSS3: Estilização visual, animações e layout responsivo.

JavaScript (ES6+): Manipulação do DOM, gestão de eventos e integração com o servidor.
